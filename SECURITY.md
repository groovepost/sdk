# Security reporting

Do not disclose vulnerabilities, credentials or tenant/customer data in public
issues. Use GitHub's private vulnerability reporting if enabled for this repository.
If it is unavailable, contact your established Groovepost support representative
privately to arrange secure disclosure. No public security inbox is asserted here.

This repository contains documentation/examples; supported SDK versions and
remediation are coordinated by the platform maintainers. Never place administrator
or provider credentials in browser examples.
