# Build with Groovepost

Use shared platform services and themed controls to build independent tenant apps.
Your app lives in its own repository and consumes released packages. No private
platform checkout is required.

Start with [installation](./getting-started.md), choose a [package](./packages.md),
then run an [example](./examples.md).

The current SDK supports typed REST access, hosted app/screen contracts, shared
web controls, entity persistence, CLI packaging and MCP tooling. Actual operations
remain subject to tenant configuration, permissions and hosted acceptance.

## Status

This is the first developer-documentation milestone. Packages remain 0.x and use
GitHub Packages with read authentication. npmjs distribution and a complete
Shopify-derived UI component library are future work. The [architecture](./architecture.md)
records that design direction without claiming every extension point is implemented.
