# Countdown widget

After registry authentication, install the exact dependencies with npm ci, then run npm run typecheck, npm test and npm run build. The current schema-3 widget owns its timer and cleans it up on unmount; it requests no platform capabilities.

Composition and title/releaseDate values live in app.config.json. Follow [repository setup and builds](../../docs/repository-builds.md) to connect the repo, configure environments and verify the live commit. The current implementation branch is pending package publication and hosted dev acceptance. No archive import or release acceptance/promotion is required.
