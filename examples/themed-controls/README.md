# Themed React controls

After registry authentication: `npm ci`, `npm run typecheck`, `npm run build`,
then `npm run dev`. Open the local URL printed by Vite.

This independent React preview composes the released Button and Field controls,
imports shared styles/fonts and demonstrates a tenant wrapper and sample CSS
variable. Saving only updates local component state. The sample branding is not
production tenant configuration; hosted apps consume platform-resolved context.
The bundler emits the required font assets and license notices must be retained.
